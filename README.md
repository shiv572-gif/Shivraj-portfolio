## ✨ Features

- **Premium Dark Palette:** Obsidian and deep slate backgrounds, glassmorphism cards (`backdrop-filter: blur`), subtle cyan/indigo/emerald accents, and ambient radial glow effects.
- **Dynamic Typing Animation:** Hero banner dynamically rotates roles for Shivraj Singh and B.Tech ECE.
- **Sticky Glass Navbar:** Blurred backdrop on scroll, active section highlighter, and reading progress bar.
- **100% Responsive & Mobile-Ready:** Sliding drawer navigation for smartphones and tablets.
- **Curated Sections:**
  1. **Home / Hero:** Personal headline, status pill, dynamic roles, call-to-action buttons, tech badge floating card.
  2. **About Me:** ECE focus, foundational engineering interests, quick facts breakdown.
  3. **Education:** Vertical timeline highlighting JECRC University (1st Semester B.Tech ECE) with relevant first-semester coursework (BEEE, Engineering Maths, C/C++ Programming, Physics, Digital Logic) and school placeholders.
  4. **Technical Skills:** Categorized into Programming, ECE & Hardware, Tools, and Engineering Fundamentals with clearly marked placeholders (`[ACTUAL SKILLS]`).
  5. **Projects:** Filterable showcase (All, Electronics & Hardware, Software & Web) with interactive details modal and repository links.
  6. **Certifications & Achievements:** Course certificates and milestone cards with clearly labelled placeholders.
  7. **GitHub & LinkedIn Spotlight:** Prominent connected cards linking directly to `https://github.com/shiv572-gif` and `https://www.linkedin.com/public-profile/settings/`.
  8. **Contact:** Interactive contact form with validation, copy email button for `[EMAIL]`, and social links.
- **Zero Dependencies:** Pure vanilla code for ultra-fast loading, perfect for GitHub Pages and Vercel hosting.

## 🌐 Free Deployment Guide

### Deploying to GitHub Pages

1. **Initialize Git & Commit:**
   ```bash
   git init
   git add .
   git commit -m "Personal portfolio for Shivraj Singh - JECRC University"
   ```

2. **Connect to your GitHub Repository:**
   ```bash
   git branch -M main
   git remote add origin https://github.com/shiv572-gif/<repo-name>.git
   git push -u origin main
   ```

3. **Enable GitHub Pages:**
   - In your repository on GitHub, go to **Settings** ➔ **Pages**.
   - Under **Branch**, select `main` and `/ (root)`. Click **Save**.
